# wrap-stage (Alias for wrap-session)

This skill is a backward-compatible alias for **`wrap-session`**, focused on concluding a meaningful work **Stage** or milestone phase. Refer to [`wrap-session`](../wrap-session/SKILL.md) for full instructions.

Follow all procedures defined in [`wrap-session`](../wrap-session/SKILL.md) to check documentation, log the stage, update `CONTEXT.md`, move completed issues to `ISSUES/done/`, and append `HISTORY.md`.
