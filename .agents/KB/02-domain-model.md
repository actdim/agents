# 02. Domain Model & Context Standards (`.agents/KB/02-domain-model.md`) [v1.2.0]

## Context & Issue Lifecycle
1. **`AGENTS.md`**: Protocol rules stamped into every repository root or nested module.
2. **`.agents/CONTEXT.md`**: Short current-state snapshot ("you are here").
3. **`.agents/ISSUES.md`**: Issue board with status (`open` | `in-progress` | `blocked` | `done`) and priority (`critical` | `high` | `medium` | `low`).
4. **`.agents/ISSUES/<type>--<slug>.md`**: Per-issue Markdown files with front-matter.
5. **`.agents/DECISIONS.md`**: Append-only ADR decision log.
